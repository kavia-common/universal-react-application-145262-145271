# Assets Setup

This app references images via the public path: /assets/<file>.

To make images available at runtime:
1) Copy all generated Figma images from the repository's assets/figmaimages directory into the app's public/assets directory.

Example:
- Source: assets/figmaimages/figma_image_2218_5205.png
- Target: universal-react-application-145262-145271/frontend_app/public/assets/figma_image_2218_5205.png

After copying, run the app:
- npm start
